## 1. 背景与语义（v9 §6/§17.2）

三级字典序三次显式 optimize：
- **L1**（可靠性）：`min Σ_t P_uns[t]·Δt`（kWh）→ 得 `L1_opt`
- **L2**（季节储能安全）：约束 `Σ_t P_uns[t]·Δt ≤ L1_opt + ε₁` 下，`min |SOC(96)−SOC_ref| + |m_h2(96)−H₂_ref(day)|/M_H2`（**均无量纲**）→ 得 `L2_opt`
- **L3**（经济/退化）：再约束 `L2 ≤ L2_opt + ε₂` 下，`min 运行成本 + 弃光（+退化代理）`

ε₁/ε₂ 的作用：**容纳求解器数值误差**（FeasTol=1e-6 级），使后层约束在浮点/MIP 数值下可行，同时**不实质放宽前层最优性**（不允许 L1/L2 目标有意义的退化）。注意：ε 语义包含"允许 L1 微退化换取 L2 改善"的字典序交换预算（实测 ΔL2 随 ε 单调增证实），冻结值应小到这种交换**工程可忽略**。
