## 0. 方案变更记录（2026-08-08，2018 前冻结允许）

- **v1（ΔSOC 拼接）**：重采样 ΔSOC 块 → 固定 SOC₀ 累积重构。实测 2 周基准轨迹（SOC 覆盖全边界 [0.15,0.95]）**无效率 100%**——拼接必然越界（块内波动幅度大 + 固定起点），CI 不可用。
- **v2 = 方案 B（当前，已冻结）**：**整周 SOC 轨迹块重采样** + **按块独立 rainflow 计数求和**。块内 SOC 为真实运行子段（MILP 约束保证物理在界内）→ 无效率≈0%；块间端点不连续不产生虚假循环（独立计数）。

## 1. Bootstrap 方案（672 点周块重采样，已冻结）

- **重采样对象**：**已实现调度轨迹**（MILP 滚动输出的命令序列）——不重采样 PV/负荷、不重新运行 EMS/MILP（v8 意见 8：条件变异语义）；
- **块长**：**672 点**（1 周 = 7×24×4，15min）；块起点 0..L−672 **步进 96**（4h）；
- **块内容**：整周 **SOC 轨迹块**（673 点=672 步）+ 同步 FC/EL 功率/启停块（同块起点）；
- **replicate** = 有放回抽取 ⌈L/672⌉ 个周块的**组合**；
- **损伤计数（关键）**：**每块独立重新调用 rainflow**（`efc_cycle_model`），replicate 损伤 = **块损伤求和**——块间端点不连续**不跨块计数**（避免虚假循环）；FC/EL 同块独立统计（块边界转换不计入启停）；
- **无效率的理论来源**：仅当块内 SOC 越界（真实子段不发生）→ 无效率≈0%。

## 2. 无效样本判定（预注册）

一个 replicate 满足**任一**条件即判**无效**：

| # | 条件 | 阈值 |
|---|---|---|
| 1 | 任一组成块的 SOC 越界 | `< 0.15 − 1e-6` 或 `> 0.95 + 1e-6`（容差与 solver FeasTol=1e-6 匹配） |

> 边界取 v9 §5.2 / `Stage2BEMSConfig`：`SOC ∈ [0.15, 0.95]`。

## 3. 剔除与认可规则（预注册，与 bootstrap_check.py 一致）

1. **剔除**：含越界块的 replicate 不计入统计；
2. **认可条件**（三条件**全部**满足才认可 CI）：
   - 前置验证（rainflow 周切块误差）相对差 ≤ **5%**；
   - 无效 replicate 占比 ≤ **10%**；
   - 有效 replicate 数 ≥ **100**；
3. **不满足时的处理（预注册）**：CI **不可用**——不静默、不事后调整阈值；论文如实报告，替代不确定性表达 = 5-seed 模型不确定性 + 参数敏感性。

## 4. 前置验证（每次运行必做）

**rainflow 周切块误差**：原始连续 SOC 轨迹 EFC 损伤 vs **按 672 点顺序分块后各块独立计数求和**——相对差应 < 5%。该误差反映跨周循环的占比：若跨周大循环贡献显著（≥5%），按块独立计数会低估损伤，CI 不可用。

## 5. 报告要求（输出 JSON 必含）

- `params`（块长/步进/n_rep/seed/边界/容差/三项阈值）；
- `pre_validate`（原始连续 vs 分块求和 EFC、相对差、pass）；
- `invalid`（无效数/率/示例）、`valid_n`、块池规模；
- `damage_ci`（BAT/FC/EL 的 median/90% CI/95% CI；有效数不足时为 null）；
- `ci_semantics`（见 §6）。

## 6. CI 语义声明（论文措辞模板，已冻结）

> 置信区间基于 **672 点周移动块 Bootstrap，对已实现调度轨迹重采样**（周块=1 单位，每块独立重新 rainflow 后求和，FC/EL 同步重采样），表示**给定 EMS 控制策略下的条件时间变异**；**不表示完整控制策略不确定性，也不表示 LSTM 参数不确定性**（后者由 5-seed mean±std 单独报告）。

## 7. 已知边界与说明

- 方案 B 的 CI 反映"周块构成/组合"的条件变异；块池规模 = (L−672)/96 + 1（2 周轨迹 ≈ 8 块），块池越大（轨迹越长）变异估计越稳定；
- 跨周大循环损伤（跨多周的大充放电循环）在独立计数下被截断——由 §4 前置验证量化，≥5% 时 CI 不可用；
- 本规则与阈值在 **2018 首次测试前冻结**（v9 意见 12/13），不得在看到 2018 结果后调整。
